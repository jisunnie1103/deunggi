# 등기등기

아파트 매매 실거래가·거래량·등기 및 계약해제 대시보드.

## 실행

`start.command`를 더블클릭하거나 프로젝트 폴더에서 `python3 server.py` 실행.
`index.html` 직접 실행도 지원합니다. 지도·웹폰트는 인터넷 연결이 필요합니다.
현재 위치는 HTTPS로 서비스하거나 localhost로 실행한 뒤 버튼을 눌러 이용합니다.
기기·브라우저에서 위치 권한을 허용해야 하며 위치는 서버로 전송하거나 저장하지 않습니다.

## 지도와 지역 선택

- 기본 지도: 수도권(서울·경기·인천). 휠 확대·축소 및 드래그 이동 지원.
- 시·도: 전국 / 수도권 / 개별 시·도. 시·군·구 필터와 통계가 함께 바뀝니다.
- `전국` 지도 버튼: 전국 범위를 선택하고 전국 지도 표시.
- 집 모양 버튼: 수도권 기본 화면으로 복귀.
- 현재 위치 버튼: 권한 허용 후 실제 위치점 및 정확도 반경 표시.
- 지역 정보: 오른쪽 슬라이드 패널. 자체 스크롤, 닫기 버튼·Escape 지원.
- 전국 지도는 시·도 대표 위치의 집계값, 서울 확대 화면은 자치구 대표 위치의 집계값입니다. 아파트 위치가 아닙니다.
- 서로 다른 지역의 중구·서구 등을 구분하기 위해 시·도 포함 전체 이름을 사용합니다.

## 전국 실거래 데이터 수집

**전국 조회 구조와 전국 수집 완료는 다릅니다.** 현재 동봉된 거래 데이터는 서울 25개 구의 2026년 10월 수집분입니다. 전국 수집 실행이 성공하기 전에는 전국 수집분으로 표시하지 않습니다. 미수집·실패 지역은 거래 0건으로 해석하지 않습니다.

`update-nationwide.command`를 더블클릭한 뒤 계약월(예: 202610)을 입력하면 됩니다.
또는 프로젝트 폴더에서 실행:

```bash
python3 -m collector.fetch_nationwide --deal-ymd 202610 --output-dir data
```

API 키는 기존 `.env`의 `MOLIT_SERVICE_KEY`를 사용합니다. 브라우저 코드에 키를 넣지 마세요.

수집기는 행정안전부 행정표준코드관리시스템에서 **현재 존재하는 법정동 코드**를 내려받아 시·군·구 단위로 조회합니다. 일반구가 있는 시의 상위 시 코드는 제외하여 중복 수집을 방지합니다. 행정구역 변경 전 과거 계약월은 당시 코드 목록을 별도 검토해야 합니다.

공식 코드 다운로드가 차단된 환경에서는 code.go.kr에서 받은 '법정동코드 전체자료.txt'를 지정할 수 있습니다.

```bash
python3 -m collector.fetch_nationwide --deal-ymd 202610 --output-dir data --registry-file /절대경로/법정동코드전체자료.txt
```

- 성공 지역은 `data/checkpoints/`에 체크포인트로 저장합니다. 실패 지역은 최대 3회 재시도하며 다음 실행에서 실패 지역만 다시 수집합니다.
- 이미 수집된 지역까지 **새로 갱신**하려면 `--refresh`를 붙입니다.
- 전국 파일 `data/molit_apt_trade_nationwide.json` 및 `.js`를 화면에서 우선 사용하며, 파일이 없으면 기존 서울 파일로 되돌아갑니다.
- 일부 지역만 성공한 경우 수집 범위와 미수집 여부를 표시합니다. 전 지역 실패 시 기존 데이터는 유지합니다.
- 수집 후 브라우저를 새로고침합니다. GitHub Pages는 저장소에 업로드된 정적 데이터만 보여줍니다.
- **자동 갱신 일정은 설정되어 있지 않습니다.** API 연결만으로 매일 자동 갱신되지는 않습니다.

공식 출처: [국토교통부 아파트 매매 실거래가](https://www.data.go.kr/data/15126469/openapi.do), [행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do).

## 검증

프로젝트 폴더에서 실행:

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/test_dashboard.cjs
node --check assets/dashboard.js
```

전국·시도·시군구 범위 집계, 미수집과 0건 구분, 7개 화면 렌더링, 패널, 수도권 지도 범위, 현재 위치 성공·권한 거부·HTTPS 조건, 수집 실패·재시도·재시작, 비정상 API 응답을 오프라인 테스트합니다. 테스트용 가상 데이터는 테스트 내부에서만 생성하며 실제 화면 파일에 저장하지 않습니다.

2026-11-05 검증 한계: 작업 환경의 외부 DNS 접근 제한으로 전국 실제 수집은 완료하지 못했습니다. 로컬 서버 실행 및 파일 URL 미리보기도 환경 제한이 있어 브라우저 시각 검증은 완료하지 못했습니다. GitHub 브라우저 접근은 승인 거부 결과가 반환되어 업로드하지 못했습니다.

## 공개 업로드 제외

`.env`, `.DS_Store`, `__pycache__`, `data/checkpoints/`, 작업 백업, 발표 자료는 올리지 않습니다.
서버는 `.env`·수집기 코드를 웹 요청으로 제공하지 않습니다.
